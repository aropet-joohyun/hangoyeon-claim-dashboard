# 한고연몰 파손 클레임 월별 비교 분석

- 운영 주소: https://hangoyeon-claim-dashboard.vercel.app/
- 배포 저장소: `aropet-joohyun/hangoyeon-claim-dashboard` (`main` → Vercel Production)
- 화면: `index.html`, 서버 API: `api/claims.js`, 변환·집계: `lib/claim-data.js`

## 데이터 기준

페이지를 열거나 새로고침 버튼을 누르면 서버가 원본 CSV를 새로 조회합니다. 열려 있는 화면은 5분마다 갱신하며, 화면 복귀 시에도 월 변경을 검사합니다. Google 측 반영 지연은 있을 수 있습니다. 원장 CSV 자체를 브라우저로 전달하지 않습니다.

- 5~8월: 기존 공개 가공 시트의 집계를 유지합니다.
- 9월: CRM `1Ju4GnBA9JtsZZckSWqZ9jRYtblLOLvhXs-upLbUFAK0`, 탭 `2026 9월` (`108127051`). 한고연 판매처의 최종 분류 `파손` → 고객 클레임, `파손반송` → 택배사 파손반송. 자유서술 메모의 키워드로 추정하지 않습니다. 기존 가공 시트의 9월 CRM 기록은 대체하며, 클레임폼 기록은 유지합니다. 서로 다른 사건은 같은 주문이어도 보존하고 동일 사건UID만 중복 제거합니다.
- 공장: `16dmX76WWbAyyHQrCnhwrw51bpmkY9n0QQ3Q0r-3gD1Q`, 탭 `2609 ` (`1947637381`). 한고연몰의 반품 원장 기록·정상 수량·원장 파손 수량을 별도 표시합니다. CRM 건수와 합산하지 않습니다. 개봉 회수 제품도 원장 파손 수량에 포함될 수 있습니다. 미입력 수량은 해당 항목 합산에서 제외하고 행 수를 안내합니다.
- 사진: `1Ml8mKk-HxHhdNL3USHUfDPcj7cw0-E-xo2P6tKzCm1w`, 탭 `클레임 데이터` (`1594296749`). 같은 파일의 `보고용` 탭은 9월 사진이 갱신되지 않아 사진 출처로 사용하지 않습니다. 9월 사진을 직접 읽고, 전체 상품주문번호·상품 계열/중량·접수일 차이 1일 이내가 일치하는 단일 고객 클레임에만 연결합니다. 연결 불확실한 사진은 별도 목록으로 보여주며 CRM 건수에 합산하지 않습니다. 원본 주문번호는 서버 내부 Symbol 속성으로만 사용되어 JSON에 포함되지 않습니다. 사진 원본 조회 실패는 0장이 아닌 `확인 불가`로 표시합니다.
- 이름·주문번호는 서버에서 마스킹합니다. 새 CRM의 연락처·주소·자유서술 상담내용은 응답하지 않습니다. 사진은 명시적인 Google Drive 링크가 있을 때만 표시합니다.
- 기존 가공 시트 조회 실패 시 전체 재시도 안내를 표시합니다. 월별 CRM 연결 실패는 해당 월만 `연결 오류 · 확인 불가`로 표시하고 다른 월은 유지합니다. 공장 원장만 실패하면 경고와 함께 CRM 집계를 표시합니다. 원본에 월 탭이 없으면 `시트 준비 중`이며 확인된 0건과 구분합니다.

## 월·연도 자동 전환

`loadAllMonths`는 `lib/month-sources.js`를 통해 **한국시간 현재 월**을 계산하고 원본 파일의 공개 `htmlview` 탭 목록에서 월별 gid를 자동으로 찾습니다. 매월 gid를 코드에 등록할 필요가 없습니다. 현재 월 탭은 원본 생성 전에도 표시되며, 향후 월은 미리 집계하지 않습니다.

- CRM 탭 이름: `2026 11월`, `2027 1월`, `2027년 1월`, `2027-01` 등 연도와 월이 명시된 형식.
- 공장 탭 이름: `2611`, `2701` 또는 CRM과 같은 연월 형식. 앞뒤 공백 허용.
- `사본`, `백업` 등 부가 문구가 있는 탭은 제외하고, 같은 월에 여러 정식 탭이 있으면 임의 선택하지 않고 연결 오류로 표시합니다.
- 2026년 8월까지의 가공 집계는 유지하고 2026년 9월 이후는 각 월 CRM을 조회합니다. 사진은 동일한 `클레임 데이터` 탭에서 해당 연월만 선택해 연결합니다.
- 2027년 1월 1일 한국시간부터 `2027-01`을 인식합니다. 여러 연도가 표시되면 탭과 그래프에 `2027년 1월`처럼 연도를 붙입니다. 열어 둔 화면도 월 변경 시 새 월로 이동합니다.
- **조건:** 기존 원본 파일에 월 탭이 추가되고 읽기 권한·열 구조가 유지되어야 합니다. 연간 원장을 새 파일로 만드는 경우 새 파일 주소 연결은 필요합니다. 새 파일 탐색이나 원장 생성·수정은 하지 않습니다.
- HTML 탭 목록 구조가 바뀌거나 접근이 차단되면 조용히 이전 월로 돌아가지 않고 연결 오류를 표시합니다.

월별 비교에는 기존 분리 그래프와 **고객 클레임 접수 수 + 택배사 파손반송 접수 수** 합계 그래프를 함께 표시합니다. 공장 반품 수량은 합산하지 않으며 확인 불가 월은 막대나 0건을 표시하지 않습니다.

## 개발·검증·배포

```sh
npm test
npm run build
npm run dev
```

로컬 미리보기: http://127.0.0.1:4173

Vercel은 `npm run build`로 생성된 `public/index.html`과 루트 `api/claims.js` 함수를 함께 배포합니다. 원본 고객 CSV는 저장소에 저장하지 않습니다. 시트의 CSV 읽기 권한이 유지되어야 자동 갱신됩니다.
