# 월 자동 전환 및 합계 그래프

사용자 승인: 월 자동 인식·원본 탭 자동 연결·과거 월 보존·준비 중/연결 오류 구분·주기적 갱신. 추가 요청: 고객 클레임과 파손반송의 월별 합계 그래프, 2027년 1월 전환.

## 구현 계획

1. 한국시간 기준 현재 YYYY-MM 계산. 공개 원본 파일의 htmlview 탭 목록에서 CRM `YYYY M월`/`YYYY년 M월`, 공장 `YYMM`/`YYYY M월` 형식만 정확히 인식한다. 사본·미래 탭·중복 월은 사용하지 않는다. HTML 구조 변경 시 추정하지 않고 연결 오류를 표시한다.
2. 2026-08까지 가공 원장을 유지하고 이후 월은 해당 월 CRM으로 대체한다. 원본 CSV는 응답·저장소에 노출하지 않고 기존 마스킹을 유지한다. 월별 조회 실패는 다른 월을 막지 않으며 실패 월은 0건이 아닌 확인 불가로 표시한다. 원본 파일을 새 파일로 교체하면 파일 주소 연결 변경이 필요하다.
3. 현재 월 탭은 원본 생성 전에도 표시한다. 2027년 이후 탭/축에는 연도를 표시한다. 5분 갱신 및 화면 복귀 시 월 변경 검사. 열어 둔 월은 유지하되 달이 바뀌면 새 월로 이동한다.
4. 기존 분리 그래프를 유지하고 합계 그래프를 추가한다. 월별 합계는 고객 클레임 접수 수 + 파손반송 접수 수이며 공장 수량은 제외한다. 확인 불가 월은 수치나 막대를 표시하지 않는다.
5. 월·연말 경계, 시트 누락/오류/중복, 미래 월 제외, 합계, 기존 9~10월 보존 테스트 후 회사 GitHub 계정으로 배포하고 운영 결과를 확인한다.

검토: DB·인증·원장 수정·별도 예약 작업은 추가하지 않는다. 자동 갱신은 웹페이지 조회/열림 시 수행한다. 원본에 월별 탭과 읽기 권한이 유지되어야 한다.
